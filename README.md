# Iam

Ядро цифровой личности: память, самомодель, мотивы и поведение, связанные причинно. Разработка идёт срезами по плану `docs/PLAN.md`.

Рабочий интеллект: **Codex, модель 6.1 Luna** (выбор пользователя 2026-10-30, D-021). Имеющийся адаптер Claude Code ещё предстоит заменить перед живыми прогонами; его тесты не являются проверкой Codex.

- Текущее состояние: `docs/STATE.md`
- Карта срезов: `docs/ROADMAP.md`
- Протокол работы проекта: `CLAUDE.md` (историческое имя файла)
- Сводка для старта: `python3 tools/memory.py brief`
- Тесты: `python3 -m unittest discover -s tests -v`
