# docker/ — изолированный исполнитель Claude Code (S08)

Рабочий интеллект личности — модели подписки Claude Code (решение D-015). Исполнитель — `claude -p` в контейнере.
Здесь описано, что собрано и как запустить на Mac. **Настоящий Docker в облачной среде разработки недоступен:** всё
ниже проверено только статически (тесты `tests/providers`), живая проверка — `scripts/claude/verify_isolation.sh`
на вашем Mac (барьер G11).

## Файлы
- `Dockerfile` — linux/arm64, пользователь 10001 (не root), Claude Code закреплён на версии, в образе нет ничего лишнего.
- `squid.conf` + `compose.yaml` — посредник с белым списком адресов (`api.anthropic.com`, `platform.claude.com`) и
  внутренняя сеть `iam-sandbox` без выхода наружу.
- Флаги запуска контейнера собирает `iam.providers.docker_run`; каждый флаг изоляции закреплён тестами.

## Что контейнер не видит
Домашних папок, базы личности, токена Telegram, Docker socket: монтирований нет вообще (`-v`/`--mount` не используются),
корневая файловая система только для чтения, `--cap-drop ALL`, `no-new-privileges`, лимиты памяти/процессов/процессора.
Домашний каталог `claude` — пустой `tmpfs` на каждый запуск (отдельное хранилище настроек; ничего не сохраняется).

## Вход в подписку (единственный секрет контейнера)
1. На Mac, вне репозитория: `claude setup-token` — выдаёт годовой токен подписки (команда ничего не сохраняет).
2. Создайте файл `~/.iam-secrets/claude.env` с одной строкой `CLAUDE_CODE_OAUTH_TOKEN=<токен>`, права `chmod 600`.
   Токен никогда не кладётся в репозиторий, журнал, экспорт или командную строку: `docker run --env-file`.
3. По документации токен позволяет только запросы к модели (не Remote Control и не коннекторы claude.ai).
4. `--bare` не используем: в этом режиме вход по подписке не читается (только `ANTHROPIC_API_KEY`).

## Запуск проверки
```
docker build --platform linux/arm64 -t iam-claude:1 docker/
docker compose -f docker/compose.yaml up -d
IAM_CLAUDE_TOKEN_FILE=$HOME/.iam-secrets/claude.env bash scripts/claude/verify_isolation.sh
```
Скрипт сам собирает отчёт `docs/evidence/claude-isolation.md`. Пока отчёт не показывает «ПРОЙДЕНА», барьер G11 не закрыт,
постоянная личность (S26, S27) не стартует.

## G09 — политики данных (проверяете вы)
Что именно уходит Anthropic при запросах по подписке и как используется, а также допустимость автоматизированного
запуска по подписке для вашего тарифа — по вашим условиям использования. Свойств API подписке мы не приписываем.
В модель отправляются только необходимые фрагменты: вид задачи, элементы контекста (ссылка, происхождение, слой, текст),
допустимые виды предложений и возможности — без идентификаторов личности и сеанса (тест `test_provider.py`).
