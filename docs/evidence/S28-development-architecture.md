Пользователь 13 ноября прямо поручил при необходимости переделать архитектуру и довести память, отношения, навыки и характер до результата в общении. Это новый содержательный объём после отрицательного D129; исторические пределы и неудачи не обнуляются.

## Контракт изменения

1. Модель получает структурированное представление уже доступного разговора. Текст, авторство, порядок, неполнота, цели, права и происхождение сохраняются. Схема ответа ограничивает citations внешними ref текущего запроса; никакого угадывания похожих ссылок.
2. Добровольная оценка практики возможна без закрытия цели. Проверяются прежние исходные цель, критерий и подтверждённый поздний результат. Один отдельный оценщик из прежнего бюджета; отрицательные оценки сохраняются. Группа навыка отделяется от проекта; перенос метода требует разных положительно оценённых результатов.
3. Социальное развитие получает доступные собственные интерпретации и контекст прежнего отношения. Три различимых прочитанных эпизода с собственными оценками могут стать основанием добровольного малого изменения существующей черты. Прежний путь изменения по действиям не меняется. Эпизоды общения не становятся независимыми доказательствами истинности чужих утверждений.
4. Возможности осмысления показываются в обычном выборе; принятие остаётся за личностью. Ни разработчик, ни сценарий не записывают нужные чувства, отношения, навыки или характер.
5. Кеш разбора текущих записей устраняет повторную проверку одинакового JSON. SQL заново определяет текущие строки при каждом чтении, получатель получает независимую копию; доступность и забывание не кешируются.
