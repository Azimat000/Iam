# D-084: единственный технический ремонт D-083

Исходная третья постановка на 755cc0d остановлена после A-options_hidden: 1 решение / 2 физических обращения. Генератор предложил один допустимый кандидат, не цель. Второй ответ native-valid, но shared-invalid: в body_json memory_write нет обязательного draft. Исходные тела и отказ сохранены в options-live. Принятых целей 0, ветвь visible не исполнялась.

Для новых ответов proposals остаётся одним упорядоченным массивом. Каждый элемент проходит одну из двух native-альтернатив: прежнее предложение с body_json (без memory_write) либо memory_write с явным draft={kind,origin,content_json}. В draft все три поля обязательны, лишние поля запрещены, виды и происхождение совпадают с прежней общей схемой. Адаптер дословно переносит поля в body.draft и только разбирает content_json как JSON-объект. Никаких исходных тем, текста, источников, целей или критериев он не дописывает. Старый ошибочный ответ остаётся ошибочным.

Местный проверяющий модуль получает стандартную операцию anyOf — хотя бы одна полная допустимая альтернатива. Старые shared-схемы не используют её и остаются прежними. Официальная документация разрешает вложенный anyOf в items: [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs). Все объекты имеют полный required и additionalProperties:false. Поддержку формы отдельно подтвердил исследователь по первичным источникам; это не живое свидетельство именно этого образа.
