## Панель R-156

`/experiments` читает упакованный `iam/panel/experiments.json`. Четыре серии, 14 полных опубликованных историй, 252 момента; 18 SHA256 исходников. Проверены воспроизводимость сборки, совпадение с исходными публикациями и включение точных JSON/модуля в `iam-0.1.0-py3-none-any.whl`. Пакет собран локальным setuptools без скачивания зависимостей. В venv нет pip, поэтому первая попытка через pip не исполняла сборку; затем использован установленный build backend. Это не ошибка приложения.

Панель не получает экспериментальные SQLite/авторизацию/приватные ключи. Query-параметры — идентификаторы серии/истории/момента, не пути к файлам. Все тексты и URL экранируются; HTML модели не исполняется. Просмотр не меняет версию/сеанс/расход личности. В наборе есть исторический отрицательный C и технически достоверные слабые биографии; данные не отбираются по удачной речи.

19 целевых тестов panel.test_experiments/panel.test_http прошли. Читатель архива — 91/91 строк и 44/44 ветви в целевом замере. Проверены XSS, неправильные JSON/типы/размер/дубли, отсутствующий файл (пустое состояние), повреждённый/недоступный (503), неверный выбор (400), восстановимые ссылки, точное чтение одного момента и отсутствие запуска/изменения личности.

Независимый кодовый проход нашёл P3: JSON true/1.0 принимались как целые номера. Основной агент исправил точную проверку типа и добавил оба отрицательных случая; целевые проверки повторены. Добавлено пояснение о моделируемых сеансах и заданных сценарием сообщениях человека. После проверки удобства навигации добавлены ссылки-якоря: выбор/следующий момент сразу открывает эпизод. Полный окончательный замер выполняется отдельно после этих изменений; первый прогон не используется как доказательство окончательного исходника.
