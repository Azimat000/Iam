При воспроизведении проверок открывали рабочую и восстановленную базы в режиме чтения, сравнили журнал, начальные поля и проверили контрольную сумму снимка. Исходный отчёт команды и итог сверки сохранены локально в `~/.iam-evidence/s26-final-20261109.e4Hafs/`. В Git сохранены только свидетельства, профиль и код.

Адресные проверки в `tests/persona/test_create.py` используют временные базы. Обычный цикл получает выбранный профиль с заглушкой провайдера. Текст непрочитанной книги остаётся скрыт. Изменение текущих предпочтений оператором не меняет зафиксированных начальных склонностей. Проверены отказ повторного создания, параллельный запуск, ошибка до публикации и ошибка синхронизации уже опубликованного каталога.

Независимая проверка обнаружила два случая, которые исправлены и проверены отдельными тестами: удаление текущего предпочтения больше не ломает составление пакета характера, а ошибка после публикации сообщает путь к уже существующему комплекту. Перед созданием оператор вручную сверяет номер решения с журналом и выбирает соответствующий файл профиля. Живых обращений к модели в S26 — 0.
