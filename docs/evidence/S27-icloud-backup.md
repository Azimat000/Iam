# S27 — зашифрованная копия iCloud и проверка восстановления

11 ноября 2026 года, D-110. Пользователь прямо разрешил использовать iCloud вместо физического внешнего носителя, проверить восстановление и продолжить проект. Смысл G16 сохранён: копия должна пережить потерю Mac, быть зашифрована и реально восстанавливаться. Это замена способа внешнего хранения, а не отмена проверки. Пользователь отдельно подтвердил: пароль сохранён вне Mac; сам пароль в чат, репозиторий и iCloud не передавался.

## Копия и облачная проверка

Подготовленный актуальный снимок включает журнал до №108, эпоху 1, версию 56 и время жизни 177 997 мс. Постоянная база остановлена. Архив содержит только `.db` и соответствующий `.json` манифеста. Файлы входа Codex и токен Telegram в него не добавлялись.

Архив зашифрован установленным GnuPG 2.5.21: AES256, AEAD OCB, итеративное преобразование пароля с солью. Пароль случайный, хранится локально в отдельном файле оператора с правами 600, вне репозитория и iCloud. До загрузки выполнены успешная расшифровка и сравнение SHA256 исходного tar.

В iCloud Drive создана папка `IAM Backups`, помещён только зашифрованный файл `IAM-backup-20261111-113238.tar.gpg`, **809 216 байт**. Рабочая SQLite в облачную папку не перемещалась. Имя архива отдельное; прежние облачные файлы не перезаписывались.

Проверка через Finder прошла следующие состояния:

1. Для файла доступно «Удалить загрузку». Выбрано именно это действие, не удаление в Корзину.
2. Finder показывает «Не загружено / В iCloud». Независимый `stat` подтвердил `dataless=true`, 0 локальных блоков при логическом размере 809 216 байт. Содержимое локальной загрузки отсутствует.
3. Нажата загрузка из iCloud. Finder показал ход загрузки, затем завершение. `dataless=false`, локальные блоки появились.
4. Скачанный файл скопирован в новый локальный проверочный каталог, SHA256 совпал с исходным зашифрованным архивом. Только эта скачанная копия использована дальше.

Смысл статусов и действий проверен по официальным инструкциям Apple: [статусы iCloud Drive](https://support.apple.com/en-euro/guide/mac-help/mchlc994344b/27/mac/27), [загрузка и удаление локальной загрузки](https://support.apple.com/en-euro/guide/mac-help/mchl1a02d711/27/mac/27). Одно копирование в CloudDocs не считалось доказательством внешнего хранения. Эта проверка доказывает функциональное получение того же файла из iCloud после удаления его локального содержимого; внутреннюю репликацию серверов Apple она не аудирует.

## Восстановление из скачанного архива

GPG успешно расшифровал скачанный файл с проверкой целостности AEAD. SHA256 полученного tar совпал с исходным. Извлечены ровно два ожидаемых обычных файла с безопасными именами: снимок и манифест. Штатная `check_backup` прошла.

`restore_backup` создал **отдельную** базу: журнал до №108 восстановлен, эпоха 1 → 2. Пройдена штатная проверка событий, снимков и SQLite. Полные события №1–108 совпадают с рабочей базой. Все группы состояния, кроме служебного раздела времени восстановления, совпадают; мир внутри этого раздела также совпадает. Время жизни 177 997 мс, одно активное намерение сохранено. Рабочая база осталась на №108 и не заменялась восстановленной.

Живых обращений к модели и Telegram — 0. Новых сеансов личности — 0. Код `src/` и тесты не менялись. Прежний полный прогон D-108 — 1 511 тестов и 154 порога — остаётся проверкой того же кода; за новый полный прогон не выдаётся.
