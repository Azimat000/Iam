## Реализация

Для текущего прочитанного обращения отдельно определяется кандидат обсуждаемого проекта. Основание — доступная показанная доставленная реплика того же контакта и её ссылка на доступный подтверждённый результат. Связь проверяется по цепочке конкретной доставки: отправка → запрос отправки → принятие → ответ → исходный запрос, с совпадением идентификаторов и порядком событий. Тексты из технического архива не используются. Поздняя отклонённая попытка с повторным ID не может изменить эту связь.

Рядом с последним общим занятием показывается последняя доступная версия связанного проекта: добавочно≤2000символов вместе с каталоговой копией. Одинаковый результат не дублируется. Скрытая/пересмотренная версия не заменяется старой или другим проектом под видом текущей. Связь — кандидат темы, не доказанное намерение собеседника; при неоднозначности инструкция требует различать проекты или уточнить вопрос.
