# S25. Разбор неизвестного элемента ответа Codex

9 ноября 2026 года. В D-091 защита остановила поток до выбора действия. В сохранившейся записи есть категория `unknown_item_type`, но самого элемента нет. Запрос, ответ и итоговый отчёт сверены на восстановленной копии исходников D-091. Повторная проверка дала те же результаты, что и первоначальный аудит.

## Что установили

- В закреплённом образе установлен `@openai/codex` 0.166.0. В исходниках этой версии у вложенного элемента ответа девять типов. У двух типов в текущей проверке один общий ярлык `unknown_item_type`. `collab_tool_call` связан с вызовом инструмента совместной работы. Вложенный `error` может означать предупреждение о настройках, устаревшей функции или перенаправлении на другую модель. Такое предупреждение может появиться без вызова инструмента. [Типы элементов](https://github.com/openai/codex/blob/6ff1e1ca3b30fc8b914720681fcf5fe62e95f856/codex-rs/exec/src/exec_events.rs#L88-L124), [вызовы совместной работы](https://github.com/openai/codex/blob/6ff1e1ca3b30fc8b914720681fcf5fe62e95f856/codex-rs/exec/src/event_processor_with_jsonl_output.rs#L224-L290), [предупреждения](https://github.com/openai/codex/blob/6ff1e1ca3b30fc8b914720681fcf5fe62e95f856/codex-rs/exec/src/event_processor_with_jsonl_output.rs#L408-L487).
- У сообщения о перенаправлении модели нет отдельного поля в потоке. В исходниках оно начинается с `model rerouted: `. По одному `item.type = error` нельзя установить, была ли использована выбранная модель. Поэтому допуск такого элемента в обычном режиме не менялся. [Формат вложенного сообщения](https://github.com/openai/codex/blob/6ff1e1ca3b30fc8b914720681fcf5fe62e95f856/codex-rs/exec/src/exec_events.rs#L286-L290), [преобразование перенаправления](https://github.com/openai/codex/blob/6ff1e1ca3b30fc8b914720681fcf5fe62e95f856/codex-rs/exec/src/event_processor_with_jsonl_output.rs#L475-L487).
- Категория D-091 также совместима с отсутствующим, пустым (`null`) или некорректным полем типа. Новые данные о точной причине исторической остановки не получены. Запуск закреплённого контейнера с отключённой сетью и искусственными данными входа дал только начало потока и дошёл до предела времени без неизвестного элемента. Подписка не использовалась.

## Готовая диагностическая проверка

[Исполнитель](../../tests/integration/codex_item_diagnostic.py) использует действующий защитный фильтр и для остановленных элементов дополнительно записывает этап события, форму поля типа и фиксированное имя, только если оно есть в опубликованном перечислении версии 0.166.0. Для вложенного `error` фиксируется только наличие признака перенаправления по указанному префиксу. Произвольные имена, идентификаторы, текст предупреждения, команды, данные входа и тело ответа в отчёт не попадают. Неизвестный элемент по-прежнему отклоняется. Общий классификатор и боевой путь не редактировались.

Пройдены 53 адресных теста. На точном сохранённом запросе D-091 с искусственными ответами проверены четыре случая. Чистый поток валиден, обычное предупреждение, предупреждение с признаком перенаправления и вызов совместной работы отклоняются и различаются в отчёте. Сохранённые записи D-091 воспроизводятся из отдельного снимка исходников. Тестовые отчёты находятся в `~/.iam-evidence/s25-codex-item-20261109`. Новых физических обращений к модели было 0.

## Предел предлагаемого обращения

Один диагностический запрос `empty-1/001` из D-091 с SHA-256 файла `792367f10faa4da3f48b4ea6c5e0bf0defec27fd9b2a00d7f815d90dc4acb526`. Модель `gpt-6-luna`, прежний неизменяемый образ `sha256:0af0b2e38184cbcca28395976e59e8579d24bb06b63980277278e99ce271e43f`, проверка изоляции и совпадения схемы до запуска, до 60 секунд, повторов 0. Исполнитель требует новую внешнюю папку и фиксирует попытку до вызова. Базы не открываются, результат не применяется, ветви опыта не запускаются. Это отдельная диагностика с собственным пределом после решения пользователя по [протоколу завершения](../COMPLETION.md#предел-работы-и-переход-при-неуспехе).

Если остановка повторится, записать только тип и допустимые признаки. Если ответ будет чистым, причина D-091 останется неизвестной. Если тип не входит в опубликованный список, останется только его форма. При любом из этих исходов завершить диагностику после одного обращения. Даже подтверждённое предупреждение само по себе не разрешает игнорировать другие предупреждения. Поведенческая приёмка S25 остаётся открытой.
