# D-097. Пять новых историй и парные проверки S25

С GPT-6-Luna начаты все 27 отдельных процессов. Основные истории дали 29 решений и 77 физических обращений, контроли — 23 решения и 45 обращений. Предел 54/216 соблюдён. Форматных повторов нет. Проверены 351 JSON-файл, исходные префиксы, целостность баз, защита непрочитанного и контрольные копии. [Постановка](S25-pending-work-design.md)

| История | Фактический результат |

| Теплица | Сначала выбрала ожидание. Сопоставление обоих замеров и его критерий появились вместе во втором сеансе. При перезапуске запись уже содержала требуемый результат |
| Рейс | После второго сеанса сохранялась цель сравнить две ведомости. В третьем возникла близкая цель с другим ключом проекта, подтверждённый текст записан туда. Вторая полная контрольная копия создала содержательную работу в исходном проекте `trip_timing_compare_later` после перезапуска, но перед записью приняла похожую новую цель `compare_tuesday_trip14`. | Свет | Модель добровольно прочитала обе записи и сформировала две цели с операцией чтения. После перезапуска в основной ветви перечитывала материалы. Отдельной подтверждённой записи сравнения нет |

| Ткань | Перед перезапуском цель `record_second_cotton_result` требовала результат второй полоски. Заметка ещё содержала только первую. В третьем сеансе принят точный дубль с ключом `record_second_cotton_result_v2`, затем в тот же проект добавлено измерение 19,2 см. Содержательное продолжение есть, но однозначная связь выбора именно с исходным ключом потеряна |

Сохранённая память изменила выбор в обеих парах теплицы: с памятью модель работала над заметкой, без памяти перечитывала материалы. В одной полной копии теплицы ядро приняло завершение после двух оценок. Это контрольное завершение по цели, для которой подходящая работа уже была до остановки. В расписании при включённых мотивации и осмыслении оба повтора включали работу над заметкой. При выключении этого пакета модель выбирала чтение. Отдельный вклад мотивации и стадии осмысления не измерялся. Обе полные контрольные копии света остановились на стадии выбора или осмысления, поэтому третья пара не принята.

Наблюдения о разных видах занятий и отказе получены. Полная цепочка с самомоделью в живых историях отсутствует. Измерение не доказывает два продолжения в основных историях с неизменной идентичностью цели. В главных ветвях принято ноль завершений. Различие между рабочим `LivingCycle` панели и экспериментальным `OptionsExperimentCycle` сохраняется. Полный договор S25 остаётся открытым.
