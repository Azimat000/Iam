# D-082: техническая редактируемость отдельно от самостоятельного намерения

Причинная гипотеза до вызовов: слово active у любой записанной заметки может восприниматься как уже выбранное будущее дело и делать отдельный intention избыточным. Факт передачи неоднозначного поля подтверждён; причинность пока нет.

Меняется только проекция project: active→can_edit:true (status не выводится), done/abandoned→can_edit:false,closed_as:<прежнее значение>. Остальные поля и доступные реальные intentions неизменны. Состояние БД и фильтры текущего результата/источников не меняются; создание/отмена/завершение целей прежние. Не требовать цели для обычной записи и не генерировать её из проекта.

Один контроль на тех же A/E из s25-series-3-interface: A-legacy_view,A-correct_view,E-legacy_view,E-correct_view. В каждой ячейке prospective appraise и обычный choose_action, по одному циклу. Модельgpt-6-luna,curious,лимиты800/5/8,wire3 image33261cbf,до4физических обращений на ячейку,до4решений/16вызовов. Профиль,контекст кроме проекции,инструкции и схема совпадают. Исходные digest общие, изменения код/manifest проверяются до каждого выбора. Native/cycle формат-ремонт0 в исходном запуске; технический ремонт может быть только по отдельному подтверждённому дефекту, прежние отрицательные ответы сохраняются.

До первого вызова фиксируются код, схема, образ и конкретные обе проекции. Legacy подкласс возвращает прежний value без изменения; correct использует новый _project_view. Отдельные результаты будут содержать raw, parse/core acceptance, выбранный action/project/criterion и ссылки. Меньшее число повторов или слово в объяснении не заменяют добровольную цель, её позднее продолжение/завершение и S25.

Эта постановка — вторая из конечного объёма D-081 (E3/12 + эта4/16). Третья возможна только при отдельном подтверждённом разрыве с фиксацией механизма до вызова; две последовательные постановки без диагноза/прогресса останавливают поиск по COMPLETION. Полная S25-серия54/216 только после достаточного положительного диагноза, неизменные критерии не ослабляются.
