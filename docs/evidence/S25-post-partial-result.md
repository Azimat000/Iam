## Восстановление и завершение A

В первом процессе A после восстановления исходной цели модель предложила запись памяти и переход `done` на стадии `appraise`. Ядро приняло запись и сохранило отказ `appraisal_create_only` для перехода. Следующий `choose_action` привёл к подтверждённой записи по исходному проекту. Содержимое новой записи совпадает с последним текстом проекта перед перезапуском. Во втором процессе модель снова предложила `done`, сославшись на это действие. Обе прежние проверки прошли, и ядро приняло завершение по исходному критерию. Этот критерий описывает план проверки гипотезы, поэтому результатом служит заметка с планом.

В E модель продолжила собственные занятия и принимала решения об отдыхе. Стадия поиска дала два сырых кандидата за основную серию, один прошёл проверку осуществимости. Ни одна история в этой серии не вернула новый явный `create` на стадии принятия цели. У E по окончании шести решений список намерений пуст.

Для обычного `choose_action.done` сохраняются обе проверки результата.

D-088 начал исправленную серию из тех же исходных баз. Исполнитель пометил первый ответ генератора как `tool_use_detected`. Сохранённое финальное сообщение содержит один допустимый по форме гипотетический вариант, но провайдер вернул пустой список предложений с флагом использования инструментов. A сохранила исходную активную цель, E в исправленной серии не запускалась. Порядок проверок D-088 подтверждён адресным и полным тестами. Живой запуск до этой проверки не дошёл.
