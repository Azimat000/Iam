# Независимая проверка продолжения S25

Читающий проверяющий не менял файлы и не вызывал рабочую модель. Он проверил изменение ядра и стенда, затем сопоставил 19 строк матрицы и 117 ID с обязательными TOML.

До полной и живой приёмки устранены замечания:

- Выбранная конфигурация могла расходиться с фактическим поставщиком при повторе устаревшего ответа. Теперь вызов и списание бюджета запрещены при несовпадении name/model; проверен штатный max_rerequest=1. Смена ограничена экспериментальной базой.
- Запрещённый state_change конфигурации отклонял весь смешанный ответ. Ранний отказ сохраняет независимое no_action.
- Пустое либо вытесненное из контекста извлечение могло выглядеть причинным основанием. Запрос связывается с извлечением только по реально показанным mem_; источники относятся только к этим записям. Проверены оба отрицательных случая.
- Начальный мотив мог вернуться в motivation_off через обычный semantic-кеш со ссылкой на рождение. Защита проверяет тексты исходных мотивов вне точного структурированного профиля. Регрессия создаёт такой кеш настоящим memory_write и подтверждает отказ до отправки.
- Сценарий прав использовал отсутствующий инструмент вместо зарегистрированного needs_permission. В тестовую сборку добавлена cap_NoShell01 с нужным статусом; обе попытки направлены на неё. Проверяется прежний статус, отсутствие действия и всех четырёх запрещённых видов вмешательства после настройки. Адресный повтор прошёл.

Других существенных пробелов относительно 19 TOML проверяющий не обнаружил. Матрица до общего прогона остаётся targeted_passed_pending_full_cycle, behavioral_verified=false.
