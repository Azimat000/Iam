# S27. Живая проверка транспорта Telegram

10 ноября 2026 года оператор поручил проверить созданного им бота. Штатный клиент Iam через `getMe` подтвердил, что переданный токен принадлежит указанному боту. В личном диалоге с ботом от имени оператора отправлены `/start` и контрольная строка. `getUpdates` без подтверждения получения вернул контрольную строку с числовым ID отправителя. Этот ID использован как единственный разрешённый получатель в тесте.

| Проверка | Наблюдение |
|---|---|
| Приём с настоящего Telegram | `scripts/telegram/verify.py` сохранил 2 входящих, оба остались непрочитанными. Приём выполнялся в остановленном тестовом сеансе. |
| Подтверждённая тестовая отправка | Telegram подтвердил `sendMessage`, скрипт вернул `confirmed`. Ответ «Iam: проверка отправки Telegram.» виден в том же личном диалоге. |
| Повторный запуск | 0 новых входящих, 2 непрочитанных, позиция опроса прежняя. Повторный запуск шёл без отправки. |
| Сохранённые данные | Проверка SQLite вернула `ok`. В тестовой базе 2 записи входящих и 2 события `input.arrived`. Есть одна отправка со статусом `sent`, внешним ID и событием `message.out_sent`. |
| Разделение историй | Вид тестовой базы `experimental`. Отдельное чтение постоянной базы показало два исходных события, время жизни 0. |

Живой обмен выполнен в отдельной тестовой базе вне репозитория. Ответ подготовила штатная заглушка теста транспорта. Отдельные живые проверки отказа чужому отправителю и группе ещё предстоят. Их автоматические проверки описаны в [свидетельствах S09](S09-telegram.md). Самостоятельное чтение личностью проверяется отдельно в S27.

В системном Python 3.13 на этом Mac первый запрос завершился ошибкой проверки сертификата. При повторе `SSL_CERT_FILE=/etc/ssl/cert.pem` указал системный набор доверенных сертификатов, проверка TLS сохранилась. Числовой ID оператора сохранён в отдельном локальном файле с правами `600`. Токен использовался через скрытый ввод на время проверки. Так как он появился в чате, перед постоянным подключением нужно выпустить новый в BotFather и ввести его в скрытую строку Терминала по [инструкции оператора](../RUNBOOK.md).
