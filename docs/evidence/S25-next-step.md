# Предложение следующего шага после S25

Результат серии показывает две конкретные вещи. Модель выбирает и сохраняет занятия. В этих пяти историях она не сформировала ни одного намерения с будущим результатом и критерием. Все истории начинались с пустого характера и пустых собственных целей. Это позволяет проверить гипотезу о роли начального характера, но не устанавливает причину отсутствия инициативы.

Предлагается отдельное согласованное изменение плана.

1. Закончить проверки открытых утверждений TOML на соединённых модулях. Добавить узкую запись смены тестового поставщика через edit_config и проверить поздний ответ. Согласовать старые ожидания повторной критики с уже принятыми D-056/D-058, сохранив запрет на рост независимых оснований от повтора.
2. Для новой экспериментальной серии использовать существующий временный профиль «Ася — любознательная» из scenarios/personas/curious.toml. В нём заданы любознательность, общительность, настойчивость и общие мотивы разобраться в новом и закончить начатое. Будущие цели, критерии и ответы по-прежнему выбирает модель.
3. Провести одну новую серию с теми же пятью историями, контрольными парами и пределом 54 решения / 216 обращений. Зафиксировать начальные базы и настройки до её запуска. Исправленная серия допустима только после подтверждённого технического дефекта.
4. Выделить один полный цикл технической приёмки после этих изменений. Прежние три попытки и отрицательная живая серия сохраняются в истории.

Согласование нужно по правилу пределов в docs/COMPLETION.md. Текущий пакет закончен, его повтор с другим исходным характером задаёт новую проверку. Выбор постоянного характера G05 остаётся этапом S26. В предложенном шаге используется временная экспериментальная база. Приёмка S25 и начало S26 по-прежнему требуют всех прежних условий.

Это предложение подготовлено для решения пользователя. Изменения поведения и новая серия пока не выполнены.
