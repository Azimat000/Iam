# Независимое ревью S18

## Первая версия, попытка 1/3

Read-only агент s18_review проверил реальные изменения относительно 6a0fe33, паспорт S18, COMPLETION и расширения D-055. Изменений файлов ревьюером не было.

1. FTS ограничивался числом доступных записей до отбрасывания скрытых совпадений. Старая запись «чай» с availability=0 могла вытеснить актуальную. Ревьюер воспроизвёл на SQLite :memory:, главный агент — на временной базе через PersistentMemory: актуальная запись есть, retrieve('чай') возвращает пустой список.
2. Cycle автоматически добавлял memory_write к явно заданному allowed_proposals=('no_action',). Нужно сохранить ограничения вызывающего кода, подключив новый вид явно в Runtime.
3. Не было парных проверок влияния свежести и важности на порядок выдачи. Проверка одной записи не доказывает ранжирование.

Это обязательные исправления первой версии, а не расширение S18. До их проверки срез не принят. Других блокеров в рассмотренном объёме ревьюер не обнаружил; итоговая версия требует повторного чтения.
