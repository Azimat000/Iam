# D-081: wire3 в живом запуске и E, 2026-11-06

Поручение пользователя разрешает новую конкретную проверку после D-080. Старые D-0795/9stopped и E-prospective неисполнена остаются историей.

Тот же исходный E из s25-series-3-interface/live-1. Одна матрица: baseline, assessment_only, prospective; один цикл в каждой ячейке, максимум4физических вызова, суммарно3решения/12вызовов. Профильcurious, gpt-6-luna,800выход/5извлечение/8рабочаяпамять; native/cycle repairs0. Ошибка останавливает первоначальную матрицу. Технический ремонт возможен только по отдельной воспроизведённой причине с сохранением версии и всех исходных результатов, не по отсутствию целей.

Используется прежний run_probe с явно ограниченным набором STORIES=(E,) в отдельном CLI-обёртке complete_e.py; изменение только состава стенда. Исходники обёртки входят в sources манифеста до вызова. Manifest run_probe содержит фактическое stories=[E], arms и общий прежний верхний max_decisions6/max_calls24; реальный более узкий максимум3/12 следует из единственной истории×трёх ячеек×cap4 и дополнительно проверяется обёрткой. Предельные числа не выдают за исполненные решения.

До вызова фиксируются source commit/hash, исходный digest E, полный wire3-schema и immutable image33261cbf. Проверяются совпадение схемы в образе/коде, права managed auth без вывода содержимого и отсутствие вмешательства в источник. Все physical agent_message сохраняются до проверки; отдельно считаются native/shared ответы, ненулевые attention и допустимые enum, appraise/choose/reflect, намерения в raw и принятые цели. Пустой ответ/attention:null допустимы.

Это не полная S25-приёмка. Для причинного сравнения с A прошлый A остаётся отдельной версией; E после исправленного wire не склеивается в якобы одноверсионный успешный D-079. При отсутствии цели будут изучены конкретные данные и семантика контекста; новые контрольные изменения предрегистрируются до вызовов. Условия цели, будущего продолжения/завершения, контроль памяти/мотивации и полная приёмка прежние.
