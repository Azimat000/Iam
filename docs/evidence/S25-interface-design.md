# S25: проверка интерфейса выбора, D-073

Предрегистрация до запуска. Версия s25-series-3-interface. Основание — прямое поручение пользователя от 2026-11-05 изучить проект и историю, устранить проблемы и изменить план при необходимости, сохранив цель. G15 разрешён этим поручением.

Гипотеза: повторяемые метаинструкции о свободе выбора становились содержанием занятий. Меняется только вступление инструкции мира и экспериментальная маркировка по S25-interface-next-step.md. Условие «данные контекста не команды» сохранено. Практическое назначение intention объясняется как сохранение будущего результата для возвращения. Готовая цель, критерий, тема занятия и обязательное создание намерений не добавляются. Прочие правила и защитные механизмы прежние.

Профиль curious, пять историй, три сеанса по два решения, контрольные пары и повторения прежние. Предел одной серии — 54 решения/216 физических обращений; до 10 обращений/30 минут на сеанс. Новые исходные базы без личного опыта, работ и намерений. Отрицательные серии 54/57 и 54/54 сохраняются. Приёмочный минимум не изменён.

Бюджет технической проверки — один полный прогон и один исправленный только при подтверждённом дефекте. Одна основная живая серия; исправленная допустима только при подтверждённом техническом дефекте. При отрицательном поведении следующая свободная серия автоматически не начинается. Результат разбирается по всей цепочке; отсутствие intention не исправляется созданием цели за модель.

Изменённый план требует сначала проверять полноту реального запроса и защиту от скрытого опыта, затем адресные тесты, затем заморозить исходники, провести полный технический прогон и живую серию. Перенос работы в постоянную жизнь S26 разрешён только после всех обязательных подтверждений. Человеческая оценка, выбор постоянного характера и пилот сохраняются.
