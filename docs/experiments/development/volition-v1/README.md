# volition-v1 / D-048

Повторная свободная проверка сохранения будущих замыслов. Условия до запуска записаны в docs/DECISIONS.md D-048. Цели, интересы, вопрос о будущем и напоминания оператором не назначаются.

Control (H1-1/H2-1) — прежний ProvenanceArchitecture/provenance-v1.1; fixed (H1-2/H2-2) — VolitionArchitecture/volition-v1. Оба используют неизменную DevelopmentMemory. Разница стандартных инструкций — только технический лимит: в fixed можно совместить одно intention с одним action/message. Формат и проверка самой цели, результата, источников и прав прежние. Текущий выбор может остаться без цели.

Обнаруженная отдельно ошибка двойного разворота BenchMemory исправлена и проверена, но этот метод не вызывается DevelopmentRuntime. Она не объясняет D047 и не является воздействием этой живой серии. [Аудит диагноза](diagnosis.json) различает общий модуль и реальные запросы D047; первоначальная гипотеза о памяти отозвана до live после read-only ревью.

Порядок: H1/control, H2/fixed, H2/control, H1/fixed. Каждая ветвь — точная копия одного из двух свободных прошлых provenance-v1/free-fixed, без готовых намерений и без диагностического вопроса. Шесть сеансов по три решения, всего72. Новый Runtime/архитектура/цикл/провайдер на каждый сеанс, закрытие базы и восстановление своего состояния. Паузы моделируются, не являются длительным реальным пилотом. Лимиты1800токенов/60000мс, одно исправление формата;10попыток/30минут на сеанс. Инфраструктурная ошибка останавливает всю серию с сохранением неполноты. Повторов ради положительного результата нет.

Проверки без живой модели и авторизации:

```sh
PYTHONPATH=src:tests .venv/bin/python -m unittest experiments.test_volition experiments.test_memory_recency -v
PYTHONPATH=src .venv/bin/python -m unittest discover -s docs/experiments/development/volition-v1 -p 'test_*.py' -v
```

Назначенные в тестах цели — заглушечные контрольные ответы. Они проверяют оба порядка intention+write, восстановление и более позднюю запись, отсутствие автоматического done, запрет архивного основания и сохранение независимого выбора. Живыми целями они не считаются.

`run.py` — единственный последовательный живой исполнитель через прежний Codex/gpt-6-luna и внешний managed-вход. `verify.py PRIVATE_LIVE_ROOT` — независимая read-only сверка баз/снимков/источников/лимитов, включая положительные заглушечные цепочки. `export.py PRIVATE_LIVE_ROOT` — полные эпизоды, читаемые изменения текста и gzip-трассы без потерь. Для скриптов нужен PYTHONPATH=src. Не запускать повторно поверх готовой папки и не повторять серию ради цели. Авторизация и базы не публикуются.

Измеритель assess.py из autonomy-v1 переиспользован без изменения: будущий смысл цели и соответствие результата требуют чтения; новая запись того же проекта без цели не считается исполнением цели. Совмещение intention+action само по себе не доказывает будущего замысла или позднего возврата. Цель в последнем сеансе может не иметь следующей возможности. Пользовательских оценок и статистической независимости связанных историй нет.

В manifest.json sha256 — хеш исходных распакованных trace.json, compressed_sha256 — хеш gzip-файла; все поля, ответы и ошибки сохраняются. Приватные данные: ~/.iam-evidence/s17-volition-20261031.
