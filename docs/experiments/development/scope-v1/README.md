# scope-v1 / D050

Отдельный ремонт после неизменной D049-серии: собственный расчёт нельзя выдавать за независимое измерение. Новый ScopeArchitecture поверх Commitment сохраняет добровольно выбранный evidence_kind: artifact / received_text / independent_observation. Вид, criterion и target неизменны; пересмотр желания возможен через явное оставление старой цели и создание новой.

Текущие операции дают текстовый артефакт или получение текста. Ни read_material, ни open_project, ни write_project не получают новых независимых измерений. Поэтому цель с independent_observation допустима, но её evidence_available/available=false, компонента0 и done по цитате собственного расчёта не принимается. Классификация производится по операции/проверенному происхождению, не словам модели. Подготовленный текст также остаётся подготовленным: тип результата не меняет авторство или биографию.

Даже принятый технический done — самоотчёт; semantic_verified=false прямо показывает отсутствие независимой смысловой оценки. Если модель неверно выберет artifact вместо независимого наблюдения, технический done всё ещё может пройти. Это предел типового слоя, не скрытая гарантия понимания.

Фиксированная ремонтная серия: F1,N1,E1 из тех же трёх prepared-источников D049, по6сеансов×2свободныхрешения=36. Ни готовых целей, ни вопросов о будущем, ни напоминаний/обязательной рефлексии нет. Новый постоянный контракт объясняет возможности операций в целом, не называет цели/числа/сцены прошлых ошибок. Каждый сеанс — новые Runtime/архитектура/цикл/провайдер, точное восстановление, моделируемые паузы без роста времени жизни. Прежние1800токенов/60000мс,одноисправлениеформата/10попыток30минут, остановка при техническом отказе. Не продлевается по исходу.

Это один повтор на контекст, проверка ремонта, не новая независимая оценка устойчивости и не замена D049. Базы и managed-вход вне Git, один писатель, прежний Codex/gpt-6-luna. prepare.py используется только для заглушечных тестов; live использует неизменные private источники D049.
