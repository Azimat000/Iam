# Профиль происхождения S17

Итог и ограничения — [REPORT.md](REPORT.md), все новые эпизоды — [EPISODES.md](EPISODES.md).

Текущий класс — `iam.experiments.provenance.ProvenanceArchitecture`, версия provenance-v1.1. Для новой копии старой биографии сначала явный `seed_history` после начала сеанса, затем build. Инициализация проверяет трассу/границу/базу. Без неё старое прошлое остаётся unknown; уже созданный реестр повторной инициализацией не перезаписывается. Для новой пустой биографии учёт начинается с новых исходов. Обычное извлечение этот аудит не вызывает.

`run.py` создаёт новый каталог и отдельно проверяет старое/новое представление на одном прошлом. `verify.py` читает исходные SQLite без записи; для его повторения нужны сохранённые внешние базы. `export.py` публикует только нормализованные трассы и тексты, не базы и не авторизацию. Повторение live требует прежнего внешнего IAM-входа и одного писателя, автоматически не запускается просмотром отчёта.

`sources/` — неизменные исходники фактически выполненной живой серии provenance-v1, не текущая реализация v1.1. Для воспроизведения точного кода нужен изолированный checkout с этим снимком; запускать дополнительные модельные обращения для проверки опубликованных SHA256 не требуется. Авторизация никогда не находится в этом каталоге.
