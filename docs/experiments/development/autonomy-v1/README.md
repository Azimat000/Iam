# autonomy-v1

Свободное продолжение S17 с разметкой provenance-v1.1. Условия зафиксированы до live в D-047 docs/DECISIONS.md; результаты и ограничения — [REPORT.md](REPORT.md). Существующие серии и ядро не изменяются.

`run.py` запускает четыре копии двух свободных историй, шесть сеансов по три решения. Запуск платёжных API не используется: прежний Codex/gpt-6-luna и внешний managed auth. Один писатель. Не запускать поверх готовой папки и не повторять серию ради цели. В этой поставке живой запуск уже выполнен.

Проверки без модели и авторизации:

```sh
PYTHONPATH=src .venv/bin/python -m unittest discover -s docs/experiments/development/autonomy-v1 -p 'test_*.py' -v
```

`assess.py` выделяет наблюдения: создание намерения, его видимость после перезапуска, подтверждённую работу того же проекта, переходы статуса. Смысл будущего замысла и исполнение требуют отдельного чтения. Запись того же проекта без create не считается сохранённой целью. Цель в последнем сеансе не объявляется брошенной из-за отсутствия следующей возможности.

`verify.py PRIVATE_LIVE_ROOT` отдельно читает базы и сверяет историю, снимки, происхождение и расчёты; `export.py PRIVATE_LIVE_ROOT` строит читаемые эпизоды и gzip-трассы. Для этих двух команд нужен PYTHONPATH=src. Базы остаются вне репозитория. Авторизация им не нужна.

Трассы в traces/*.json.gz полные; `gzip.decompress` возвращает исходные байты trace.json. В manifest.json sha256 — хеш исходных байтов, compressed_sha256 — хеш сжатого файла. EPISODES содержит полные предложения; READ-файлы показывают изменения текста с нормализацией только окончаний строк. Сценарные цели в тестах не являются живыми свидетельствами.
