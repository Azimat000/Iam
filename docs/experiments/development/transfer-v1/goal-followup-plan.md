# S17: следующая узкая проверка собственной будущей цели

Это исходный план продолжения. D-043/D-044 выполнили единственный необязательный вопрос на копии живого прошлого: модель выбрала no_action, целей0, ветвей0, повторных вопросов0. [Результат](goal-probe/REPORT.md). Части ниже с парными ветвями **не выполнялись**, так как условие собственной цели не наступило. S17 не закрывается, вопрос в этой постановке не повторяется.

## Что именно остаётся неизвестным

Если активного принятого намерения нет, формула goals передаёт те же числа, что needs. Разный последующий выбор при разных названиях режимов не доказывает влияние цели. Короткая жизнь без сохранённого будущего намерения не доказывает и неспособность его сформировать. Требуется испытать незадействованную часть механизма, сохранив право не создавать цель.

## Общая подготовка без вымышленной цели

Использовать отдельную копию одной достоверной живой истории A с собственной подтверждённой работой. Сам текст цели нельзя задавать заглушкой или разработчиком. Допустим один явно помеченный необязательный вопрос о будущем результате после чтения своего текста: предложить собственный конкретный замысел с источником либо выбрать no_action. Это вызванное постановкой осмысление, не спонтанное возникновение цели. Отсутствие цели сохраняется; бесконечное повторение вопроса и усиление формулировки до нужного ответа запрещены.

Проверить происхождение принятого намерения, точную будущую работу и доступность соответствующего действия. Если модель не предложила допустимой цели, сообщить неполноту без подстановки ScriptedGoals. Для отдельной проверки спонтанности позже потребуется более содержательная жизнь, не давление в инструкции.

## Парные ветви

Из одной остановленной копии с настоящим принятым намерением — needs/goals/off, два повтора, не более четырёх решений на ветвь. Один провайдер/модель, одинаковые события, контекст и бюджеты; исходы и форматные повторы сохраняются. Для каждого решения отдельно пересчитать источник, состояние цели, числовой бонус и последующий фактический результат. Любая новая запись недостаточна для выполнения цели: нужен просмотр смысла исходного замысла и результата.

Важно: в текущем off выключены числовая таблица и исходные мотивы, но остаётся доступное состояние собственного намерения. Такая ветвь проверяет добавочный эффект таблицы, а не полное удаление мотивации. Для проверки влияния самого намерения потребуется отдельный явно спроектированный контроль: исключить его из всех проекций контекста, не подмешивать его текст из архива/прошлых запросов и сохранить равенство остальных доступных оснований. Не называть нынешний off полным отключением желаний.

## Условие решения

Различать три свидетельства: транспорт собственного замысла, прослеживаемое продолжение после опыта, добавочный причинный эффект таблицы. Одинаковое поведение допустимо и не доказывает превосходство. Даже успешно выполненная вызванная вопросом цель не подтверждает естественное возникновение устойчивых собственных целей. После проверки можно принять ограниченное инженерное решение о механизме с сохранением непроверенных свойств для S22/S25; R-080 и закрытие S17 не повышаются заранее.

До реализации отдельно уточнить границы/проверки в DECISIONS. Основная серия transfer-v1 не переписывается и не дополняется задним числом новыми ячейками.
