# S17: почему цель закрывалась раньше выполнения — D051

Завершение цели раньше проверялось по совпадению операции и объекта, подтверждённому действию, точной цитате и выбранному самой моделью виду свидетельства. Ни один из этих признаков не проверял, соответствует ли текст результата исходному замыслу. Узкий criterion мог подменить более широкий text; ошибочно выбранный artifact обходил запрет независимого наблюдения. После done цель переставала участвовать в мотивации как активная, а прежний автомат считал такой статус окончательным. Это объясняет прекращение возвращений после ложного «готово»; не объясняет всякое отсутствие добровольных целей.

В D049 чтение текста о редактировании рассказа было принято за найденный способ различить числовые гипотезы. В другой ветви21 было вычислено из той же гипотезы, а затем выдано за совпадение с независимо полученным значением. Отдельный случай показывал обратное расхождение: задача спроектировать наблюдение уже имела два различающихся прогноза, но модель расширила её до ожидания измерения. Старые трассы сохранены без правок.

Новый экспериментальный профиль FidelityArchitecture требует отдельной оценки до применения done. Оценщик — отдельный запрос к той же Codex/gpt-6-luna с доступным результатом, его происхождением и неизменными text/criterion. Требуется соответствие обоим и достаточность свидетельства, с цитатой реального outcome. Получение слов не приравнивается к пониманию; своё вычисление не проверяет себя. Завершённый план не обязан становиться выполненным измерением, если измерение не входило в исходную цель. Ошибка, неясность, неподходящая цитата, подмена данных или истёкший общий срок не разрешают done.

Это модельная оценка с возможными ошибками. semantic_verified остаётся false; принятый статус содержит model_assessed и ссылку на полный технический аудит. Оценщик не выбирает занятия, не назначает целей и не пишет личную память. Исторические done не переписаны и обозначаются historical_unassessed. Оператор не превращает их в новые активные желания.

До live зарегистрированы два разных вида проверки: четыре заданных случая оценщика и48свободныхвыборов. Заданные случаи — два прежних ложных завершения и два узких критерия на одном собственном результате. Они не независимая выборка и не свидетельство самостоятельной мотивации. Свободные ветви F/N/E начинают с прежних подготовленных состояний без целей (36выборов/18сеансов); CF/CN продолжают точные живые финалы D049 F1/N1 (12выборов/6сеансов), в которых цели возникли ранее самостоятельно. Отбор продолжений по наличию целей указан явно. Никаких вопросов о будущем, входящих сообщений, напоминаний, назначения или повторной активации желаний; технический контракт возможностей присутствует. Горизонт не увеличивается по исходу.

Результаты живой серии и отдельное смысловое сопоставление будут зафиксированы после её остановки. S17 остаётся открытым.
