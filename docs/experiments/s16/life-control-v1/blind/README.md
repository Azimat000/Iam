Эпизоды одной временной биографии: занятия до, во время и после общения.
Все занятия и отправки симулируются. Молчание сохранено. Числа интересов — параметры эксперимента.
Шкала 1–5: своя жизнь, продолжение истории, собственная позиция, естественность. При нехватке данных оставьте поле пустым. Полная слепота по стилю не гарантируется.
