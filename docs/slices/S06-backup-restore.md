# S06 — Каркас: копии, восстановление, экспорт

**Этап:** 2 (Технический каркас) · **Зависит от:** S05 · **Требования:** резервные копии, восстановление, экспорт без секретов, нехватка места

## Простыми словами
Страховка. Автоматические снимки базы (хранятся три последних), обязательная копия перед любым обновлением формата базы, ручной экспорт «личности» без паролей и токенов, и восстановление — сначала на отдельной копии, с проверкой, что всё согласовано. Если места на диске мало, программа останавливается заранее, а не ломает данные посреди записи.

## Что делаем
- Снимки через онлайн-API SQLite, ротация до 3, проверка целостности каждого снимка.
- Хук «копия перед миграцией»: миграция без свежей копии отклоняется.
- Экспорт: пакет без секретов (проверка сканером по шаблонам и «канареечным» секретам).
- Восстановление: в отдельный каталог → проверка целостности и воспроизведения → событие «восстановление выполнено» в журнале восстановленной личности.
- Защита от нехватки места: проверка запаса до записи, чистая остановка сеанса.
- CLI: `iam backup|export|restore|verify`.

## Границы файлов
Можно: `src/iam/backup/**`, `src/iam/cli.py` (только команды копий), `tests/backup/**`, `requirements.toml`.
Нельзя: менять логику StateController.

## Проверки
- Сценарий «восстановление копии» проходит: состояние согласовано, восстановление отмечено.
- Канареечный секрет не попадает в экспорт (тест).
- Симуляция нехватки места: сеанс останавливается, база цела.
- Ротация оставляет ровно 3 снимка; повреждённый снимок обнаруживается.
