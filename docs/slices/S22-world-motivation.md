# S22 — Ядро: мир, мотивация, намерения

**Этап:** 4 · **Зависит от:** S21 · **Требования:** собственный мир, действия с условиями и последствиями, жизненный цикл намерений, выбранная мотивация

## Простыми словами
У неё появляется свой маленький мир без графики: личное пространство, библиотека загруженных текстов, место для собственных произведений. Каждое действие имеет условия, длительность и результат: прочитанное получает отметку о *реальном* прочтении, написанный текст сохраняется как отдельная работа, проект можно начать, продолжить, закончить или бросить, перестановка в пространстве переживает перезапуск. Воображаемое не считается выполненным. Здесь же подключается выбранный в S17 механизм мотивации: из него растут интересы, выбор занятий, ожидание результата и перемены предпочтений. Намерения живут по циклу (активное / ждёт возможности / отложено / выполнено / оставлено); знать о действии, хотеть его и иметь право его выполнить — разные состояния.

## Что делаем
- `iam.world`: места, материалы, предметы, проекты; действия с предусловиями, длительностью, результатом; сохранение между перезапусками; отметка фактического чтения; работы как отдельные объекты.
- `iam.intentions`: состояния намерений, три различия (знает / хочет / вправе), ожидание, отложить, оставить.
- `iam.motivation`: выбранный в S17 механизм; обратная связь, смена предпочтений.
- Загрузка материалов в библиотеку оператором; панель: мир, проекты, намерения.

## Границы файлов
Можно: `src/iam/world/**`, `src/iam/intentions/**`, `src/iam/motivation/**`, панель (страницы мира), `tests/world/**`, `tests/intentions/**`, `tests/motivation/**`.
Нельзя: интерфейс Capabilities (S23), самомодель (S24).

## Проверки
- Сценарии «новый интерес» (ссылка на события/результаты), «отсутствие новых сообщений» (собственные занятия, продолжение проекта, бездействие), «пауза и перезапуск» (мир и намерения сохранены) проходят.
- «Воображаемый результат» не меняет мир (тест); сбой посреди действия не оставляет «наполовину прочитанного» без отметки.
- Шесть проверок мотивации из S15 повторяются уже на реальном ядре.
