# S00 — Основа проекта и память между сессиями

**Этап:** 0 (подготовка) · **Зависит от:** — · **Требования:** процессные (память, протокол, честность статусов)

## Простыми словами
Прежде чем строить личность, нужно построить «записную книжку проекта». Claude Code не помнит прошлые сессии, поэтому всё важное хранится в репозитории: план, разбиение на срезы, что сделано, какие решения приняты, что ждёт вашего действия. Новая сессия читает эти файлы сама и продолжает с того места, где остановилась — вам ничего пересказывать не нужно.

## Что делаем
- Сохраняем план дословно (`docs/PLAN.md`) — источник истины.
- Делим работу на 30 срезов (`docs/state.json`, `docs/slices/*`, `docs/ROADMAP.md`).
- `CLAUDE.md` — протокол сессии (старт → работа → закрытие), загружается автоматически.
- `tools/memory.py` — состояние срезов, барьеры, допущения, журнал, проверка целостности.
- `docs/DECISIONS.md` — журнал решений; `docs/JOURNAL.md` — хронология.
- Тесты инструмента памяти.

## Границы файлов
Можно: `CLAUDE.md`, `README.md`, `.gitignore`, `docs/**`, `tools/memory.py`, `tests/test_memory_tool.py`.
Нельзя: `src/**` (кода личности ещё нет).

## Проверки
- `python3 -m unittest discover -s tests -v` — зелёное.
- `python3 tools/memory.py check` — «память проекта согласована».
- Все 30 файлов срезов содержат обязательные разделы.
- Жизненный цикл `start → finish` проверен тестом на временной копии.

## Итог
**Сделано.** Создана вся «память»: план (дословно), 30 срезов с описаниями, протокол сессии в `CLAUDE.md`, инструмент `tools/memory.py` (brief/start/finish/block/gate/assume/log/render/check), журнал решений D-001…D-004, генерируемый `STATE.md`.

**Как проверено.** Модульные тесты инструмента на временной копии; `memory.py check` на реальном репозитории; независимый просмотр границ файлов.

**Не сделано / ограничения.** Ничто в самой личности (это S01+). Допущение A1 («вместо Codex — Claude Code» = разработка; рабочий интеллект остаётся заменяемым) ждёт подтверждения пользователя. Непрерывность между сессиями зависит от того, что новая сессия увидит ветку с этой памятью (см. CLAUDE.md, шаг «Старт»).
